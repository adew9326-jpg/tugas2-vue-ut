1. Stok Bahan Ajar

WAJIB

Modul pengawasan stok bahan ajar untuk seluruh UPBJJ UT Daerah dengan sistem status tiras otomatis (Aman, Menipis, Kosong) dan peringatan re-order dini.

  • Tabel data stok lengkap dengan lokasi rak & catatan HTML
  • Status visual otomatis: 🟢 Aman, ⚠️ Menipis, ⛔ Kosong
  • Filter dependent: Pilih UT Daerah baru muncul Kategori MK
  • Filter cepat Re-Order (Stok < Safety Stock / Stok = 0)
  • Pengurutan data (Sort by Judul, Stok, Harga) tanpa recompute
  • Formulir tambah dan edit bahan ajar dengan validasi
  • Watcher otomatis pemantau status tiras kritis

2. Tracking Delivery Order (DO)

WAJIB

Modul transaksi registrasi pesanan bahan ajar baru dan tracking riwayat ekspedisi pengiriman Delivery Order (DO) mahasiswa secara terpadu.

  • Nomor DO otomatis tergenerate: DO{Tahun}-{Sequence 3 Digit}
  • Input formulir pemesanan mahasiswa (NIM, Nama, Ekspedisi)
  • Pilihan paket bahan ajar dengan rincian buku dinamis
  • Sinkronisasi harga otomatis dari master data paket
  • Fitur Date lokal untuk pengisian tanggal kirim instan
  • Pelacakan real-time nomor DO (Live search watcher)
  • Visual Stepper Timeline riwayat perjalanan ekspedisi

🎯 Pemenuhan 5 Indikator Capaian Hasil Belajar (Tugas Praktik 2 Vue.js)

Status: 100% Terimplementasi Lengkap

1. Struktur & Organisasi Kode

Pemisahan arsitektur folder bersih: index.html, stok.html, tracking.html, css/style.css, dan file JS terpisah.

2. Data Display & Directives

Penerapan mustaches {{ }}, v-text, v-html untuk format HTML catatan, serta v-for untuk list rendering.

3. Conditional Directives

Implementasi v-if, v-else-if, v-else untuk status stok (Aman/Menipis/Kosong) & v-show untuk filter dependent.

4. Binding, Computed & Methods

Two-way binding v-model, computed property dengan caching tanpa recompute, generator nomor DO, dan methods helper.

5. Watchers Berfungsi Penuh

Lebih dari 2 watcher untuk deteksi perubahan UT Daerah, peringatan re-order tiras kritis, auto-sync harga paket, dan live tracking.
